# TaskFlow – Premium Task Management Application

A modern, full-stack task management platform designed with a premium SaaS experience. The application enables users to create, organize, prioritize, and track tasks efficiently through a clean editorial-inspired interface, secure authentication, and dynamic dashboards.

## ✨ Features

- Secure JWT Authentication
- User Registration & Login
- Task CRUD Operations
- Kanban Board
- Task Prioritization
- Search & Filters
- Responsive Dashboard
- Analytics & Progress Tracking
- Activity Timeline
- Dark & Light Mode
- Real-time Updates (Socket.io)
- Premium UI with Smooth Animations
- Mobile Responsive Design
